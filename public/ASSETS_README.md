# Asset Placement Guide

Bu dosyayı sil ve görselleri aşağıdaki konumlara kopyala.

## Logo
```
public/images/logo.png
```

Serotonin molekülü logosu — SiteNav ve Footer'da kullanılıyor.

## Release Artwork — Sınırları Aştın
```
public/artwork/sinirlariastin.jpg
```

İstanbul silueti, kırık cam, karanlık atmosfer — ReleaseSection hero görselidir.

## Sonra
Görselleri yerleştirdikten sonra `npm run dev` ile uygulamayı başlat.
